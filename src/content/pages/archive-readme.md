This file is documentation only (not shown on the site).

**Admin → Pages:** create, edit, or delete pages. Each page is published at `/p/your-page-slug` unless you set a custom **URL Path**.

**Navigation:** enable **Show in Navigation** on a page — it is added to the menu automatically. Use **Nav Order** and **Parent Menu Key** for ordering and submenus. You can also manage the full menu under **Navigation Menu**.
